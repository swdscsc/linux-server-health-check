# Security policy

## Reporting a vulnerability

Please do not publish exploitable vulnerability details in a public issue.

If GitHub's private vulnerability reporting is enabled for this repository, use **Security → Report a vulnerability**. Otherwise, contact the maintainer through the contact options on the maintainer's GitHub profile: https://github.com/swdscsc

Include the affected version, impact, reproduction steps, and a suggested mitigation when possible. Do not include real access tokens, passwords, or private production data in reports.
